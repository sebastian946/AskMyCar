¿Cómo reviso el nivel de líquido de frenos?

smart_toy

Para revisar el nivel del líquido de frenos en tu 2019 Renault Sandero, sigue estos pasos:

1. Estaciona el vehículo en una superficie plana.
2. Abre el capó y localiza el depósito translúcido cerca de la pared de fuego del lado del conductor.
3. El nivel debe estar entre las marcas MIN y MAX.
4. Si es necesario rellenar, utiliza únicamente líquido tipo DOT 4.
